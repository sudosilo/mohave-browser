Mohave Browser

Mohave Browser is a small Android web browser. It is for people who want a simple phone browser built on the Firefox engine.

It opens a start page and has an address bar, a back button, a reload button, and a progress bar. Each session is one tab. A build runs automatically on every push.

This app is checked every morning by Control Troll.

Latest change. First build of the browser. The build setup was trimmed and updated for the newest Gecko engine.
